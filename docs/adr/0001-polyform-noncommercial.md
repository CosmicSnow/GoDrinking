# Source-available com PolyForm Noncommercial 1.0.0

O código vai ser público, mas “open source OSI” permite uso comercial sem pedir. O que queremos é: ler e usar em hobby/pessoal/ONG, e **uso comercial só com autorização explícita**.

**Decisão:** `PolyForm-Noncommercial-1.0.0` (SPDX). Texto em `/LICENSE`. SPDX no `package.json` e `Cargo.toml`.

Isto **não** é Open Source OSI. É source-available. AGPL deixaria um SaaS comercial usar o código se abrisse o fork — não bloqueia “aproveitar”. PolyForm Strict proíbe até distribuir builds; é demais para amigos compilarem.

Licença comercial à parte, por escrito, quando alguém quiser vender ou hospedar isto.
